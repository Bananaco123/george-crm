# George CRM

基于 React 19 与 Vite 8 的独立 CRM 工作台。侧栏品牌显示 CRM，移除工作空间切换模块及“演示空间”；客户管理分组下仅保留线索管理、客户管理两项，按此顺序展示。工作台提供完整演示，其他导航共用简化示例列表，携带的筛选条件直接作用于数据，支持搜索、部门、成员、等级、状态和日期筛选。

## 运行

独立安装使用 Node.js 24、pnpm 11.25.0，依赖版本由 `pnpm-lock.yaml` 锁定。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

在本目录执行：

```powershell
node scripts/run.mjs dev
```

预览地址：`http://localhost:5188/`。端口被占用时会报错，不会静默改到其他端口。

未安装本项目依赖时，启动脚本会只读复用相邻 `GOS V1.0/demo V1.3/node_modules` 的工具链。George CRM 的源码、样式、缓存和构建目录均独立，旧项目不受修改。独立开发与部署使用：

```sh
pnpm test
pnpm build
```

本工作区构建与数据逻辑测试：

```powershell
node scripts/run.mjs build
node --test src/data.test.mjs src/conversations.test.mjs src/destinationData.test.mjs
```

## 在线部署

- 代码仓库：https://github.com/Bananaco123/george-crm
- 在线 Demo：https://bananaco123.github.io/george-crm/
- 源码保存在 `main`，网站使用 `gh-pages` 分支的根目录。Vite 使用相对资源路径，兼容仓库子目录；不要将 `dist`、`.vite` 或 `node_modules` 提交到源码分支。
- 后续更新：提交源码并推送 `main` 后，执行 `pnpm deploy`。该命令运行测试、构建网站，再通过已认证的 GitHub CLI 将本次产物提交到 `gh-pages`，由 GitHub Pages 完成发布。
- 发布需要本机已安装 GitHub CLI，且登录账号拥有本仓库写权限；脚本不会读取或保存明文凭据。当前发布方式不需要额外的 Actions 工作流写权限。

## 当前范围

- 时钟与时区位于工作台标题行最右侧，标题旁不再展示日期。部门、成员和统计周期在左侧业务区的同一行排列。
- 业务概览默认展示十项指标，两行各五张：第一行为投放消耗、询盘进线、线索转派、新建客户、到店客户，第二行为新建项目、新建商机、新建报价、业绩金额、输单项目。右上角齿轮支持从十五项中选择一至十项，新增备选为跟进待办、逾期待办、成交商机、实收金额、报价金额；可保存、取消或恢复默认，设置在当前浏览器刷新后保留。线索转派右侧用单行标签展示 A 类数量，主数值仍为全部转派线索。
- 统计周期提供昨日、今日、近 7 天、近 30 天快捷选项，默认近 30 天；旁边始终显示起止日期，可直接修改进行自由筛选，包含首尾两日，结束日期不能晚于今天。部门和成员使用统一圆角下拉菜单，展开时显示蓝色边框与焦点外圈，支持键盘选择。对比使用紧邻当前周期之前的等长日期区间，文案统一为“较上周期”；基期为零显示 `—`，增长红色、下降绿色、持平灰色，金额缩写中的“万”与其他单位使用相同小字号。新建商机按创建日期统计，输单项目按项目输单日期统计。
- 部门筛选沿用 GOS 的五个营销中心：威猛创客中心、启明创客中心、天马创客中心、出海找我、Wisdom创客中心。部门、成员和统计周期共同作用于业务概览与项目商机，不影响日历、待办及业务工具；看板按项目或商机的创建日期筛选，指标按各自的业务发生日期统计。切换部门时，无效的成员选择自动重置。业务概览使用独立白底容器。
- 左侧业务区与右侧日历待办始终保持 3:1；右侧拆分为“我的日历”和“待办中心”，与左侧“业务概览”和“项目商机”共用网格行，使模块间留白与分界始终对齐。日历点击日期直接筛选待办，支持月份切换与今天定位，移除“所选日期”下拉。
- 项目商机工具栏在同一行提供项目名称/客户搜索、商机视图与项目视图切换。连续箭头阶段条下纵向排列卡片，商机视图宽屏约显示 4.5 列，窄屏保留卡片最小宽度；整个看板内容区均可按住左右拖动，松开时吸附。悬停阶段条使用滚轮横向浏览，卡片区仍可纵向滚动。两侧保留固定白边及溢出渐隐，无记录的阶段保持空白；不显示工具栏左右翻页箭头。
- 指标、项目、商机及待办卡片整体可点击，跳转至侧栏对应页面的示例列表。指标、项目与商机携带部门、成员、日期范围及当前业务条件；待办携带自身的日期、类型、编号、状态及负责人，不受左侧业务筛选影响。条件写入 URL，支持浏览器返回。列表可继续修改或清除筛选、分页浏览，项目、商机和待办可打开既有详情。通用示例列表用有限样本演示筛选，不将样本数当作业务概览中的完整指标总量。拖动看板不会误触跳转。商机的关联项目链接、创建日期与业务字段统一放在灰色信息区，不展示编号、订单类型行及详情按钮；创建日期格式为“创建于 2026-10-05”。关联项目链接同样携带条件跳转。
- 商机卡片、展开的关联商机及详情统一展示项目等级和阶段停留标签，等级在左、停留时间在右。停留时间按进入当前阶段的日期计算，不足一天显示“停留不足 1 天”，其余显示“已停留 N 天”；达到十天使用橙色警示图标及“超时”标记。项目与商机共用 A、B、C、D 四级标签，分别使用玫瑰、琥珀、蓝、紫色，保留字母区分；未知等级显示未评级，不归入任何一级。
- 项目卡片不展示编号及已报价/已成交汇总行，“方案设计”及状态、创建日期放在灰色信息区；尚未发起设计的项目显示“未发起”标签。展开商机完整占位，在所属阶段内纵向滚动，不压缩或覆盖后续卡片。
- 指标图标分别表达投放、询盘进入、线索转派、新建客户、新建项目、新建商机、报价单、到店、金额和输单项目；输单使用文件夹叉号，不使用趋势箭头表达指标类别。
- 看板横向滚动条及各阶段纵向滚动条仅在滚动时显示，停止滚动后自动隐藏，避免显示变化导致内容跳动。
- 项目阶段：待成交、部分成交、全部成交、已输单。商机看板从洽谈中开始，依次为报价中、待下单、交付中、已完成、已输单。默认近 30 天且未限定部门、成员时，项目与商机各阶段均有至少三项演示数据，包含不足一天及十天以上停留的示例；施加筛选后可少于三项或为空。底层保留待接受/已拒绝状态，可在关联商机中查看。
- 商机字段按 GOS 展示方案经理、商机部门、订单金额、实收金额；商机部门继承所属项目营销中心。项目展示负责人、交付经理、项目金额、实收金额；金额均以普通字段呈现。
- 洽谈中商机尚无订单金额、实收金额，报价中尚无实收金额，数据使用空值并显示 `—`，不以预计金额或 `0` 代替。卡片与详情使用同一规则。
- 项目与商机均可打开详情，提供关联会话与 AI 销冠入口。项目详情关联项目群及所属商机私聊，商机详情只关联自己的私聊和所属项目群。销冠规则分析展示会话摘要、下一步建议与回复草稿，可定位客户原文并复制草稿；不会自动发送消息。返回详情保留原项目或商机上下文。
- 设计类型和设计状态独立展示。项目成交聚合排除设计服务与待接受/已拒绝商机；已完成产品商机保留成交结果；零有效商机不判为全部成交。项目手工输单不影响商机状态。
- 待办中心提供全部待办、跟进待办、项目待办、报价待办四类，按日历日期筛选并支持分页；任务详情为查看模式。
- 沉睡客户可添加本地跟进待办，同步日历、任务数量，并在当前浏览器刷新后保存。
- 定时推送展示计划预览，尚未接入推送服务；数据分析展示基于演示数据的规则结果，尚未连接模型服务。

所有客户、项目、金额和任务均为演示数据。客户、项目和商机名称采用 GOS 海外业务场景的英文或中英文命名；旧浏览器缓存中的待办名称自动同步，保留任务状态、日期与时间。会话和销冠分析为本地演示，未连接真实消息或 AI 服务。不存在后端业务写入、对客户发消息或真正的后台定时任务。日程相对打开页面时的北京时间生成；本地新增跟进按北京时间日期隔离保存。

## 设计依据

用户提供的业务后台及阶段条参考图：深蓝导航、浅灰蓝工作区、白色独立卡片、蓝色选中态、连续箭头阶段条使用低饱和渐变色，对应卡片左边缘使用同色细条，展开的关联商机按自身阶段着色。字段、角色与部门口径参考 GOS `src/pages/MindDashboard/ProjectDashboard.jsx` 及 `src/mock/projectDashboard.js`，颜色和字号参照其现有主题。页面只保留中文业务文案与必要品牌、专有名称，不添加装饰性英文或口号。

海外业务 Mock 参考 GOS `src/mock/projectDashboard.js` 的 Kanchan、Joseph、Sofia、Emily、Miguel 等项目，以及 `src/mock/operationsDashboard.js` 的新加坡、马来西亚、沙特客户场景。关联会话入口参考 `src/pages/MindDashboard/ProjectDashboard.jsx`；消息字段参考 `src/mock/imStore.js`。演示会话按当前项目、客户与商机分别生成，不共用其他客户的历史会话。

工作台按桌面业务场景设计，窄窗口保留最小内容宽度并允许横向查看，维持两行指标和左右 3:1，不将右侧待办排到页面底部。

## 文件入口

- `src/App.jsx`：工作台筛选联动、导航及弹窗交互。
- `src/components/Metrics.jsx`、`src/metric-settings.css`：指标卡及十五选十的展示设置。
- `src/components/DateRangeControl.jsx`、`src/filter-toolbar.css`：预设周期、常显起止日期及顶部筛选样式。
- `src/components/FilterDropdown.jsx`、`src/filter-dropdown.css`：部门与成员共用的下拉菜单和键盘交互。
- `src/navigation.js`、`src/components/DestinationPage.jsx`：带条件的 URL 导航、通用示例表格及关联详情入口。
- `src/components/Workbench.jsx`：阶段看板、日历待办与业务工具。
- `src/components/ProjectLevelTag.jsx`、`src/components/StageDurationTag.jsx`：卡片与详情共用的项目等级、阶段停留及超时标签。
- `src/styles.css`：导航、通用控件和弹窗基础样式。
- `src/workbench.css`：工作台 3:1 布局、指标卡、阶段条与业务卡片。
- `src/workbench-features.css`：等级、超时、日期筛选及说明页的功能样式。
- `src/board-polish.css`：仅作用于项目商机模块的独立视觉优化，包括层高、留白、卡片边界和字段层次。删除 `src/main.jsx` 中该文件的 import 即可回退本轮看板视觉调整，保留功能及数据变更。
- `src/board-colors.css`：独立阶段渐变和卡片边条；移除对应导入即可回退本次阶段配色。
- `src/project-levels.css`：A/B/C/D 级标签的独立视觉映射。
- `src/destinationData.js`、`src/destinationData.test.mjs`：示例列表统一数据、真实筛选及测试。
- `src/destination-table.css`：通用列表布局、条件标签和分页样式。
- `src/data.js`：演示数据、指标和状态聚合。
- `src/data.test.mjs`：状态、引用完整性和统计测试。
- `src/conversations.js`：项目与商机会话、消息及规则分析演示数据。
- `src/components/ConversationPanel.jsx`：会话阅读、销冠分析、原文定位与草稿复制。
- `src/conversations.test.mjs`：会话归属、客户隔离与上下文引用测试。
- `src/components/Icon.jsx`：本地图标，无外部字体或图片依赖。
